# Sergey Moloman

Sergey Moloman is an AI product engineer who builds tools for coding agents, including co-od, Pathmark and Brow, and voice AI for sales teams.

Site: [moloman.dev](https://moloman.dev) · X: [@sergey_moloman](https://x.com/sergey_moloman) · Email: sergey@moloman.dev

## What I've built

| Product | What it does |
|---|---|
| [Roleplay](https://moloman.dev/work/roleplay) | A voice training simulator. An AI customer built from your website: your team calls it, sees the second to fix, and tries again. |
| [Brow](https://moloman.dev/work/brow) | Puts your MacBook's notch to work: your coding agents ask permission there. |
| [co-od](https://moloman.dev/work/co-od) | Run Codex, Claude, Grok and other coding agents with your team in shared Mac rooms. |
| [Pathmark](https://github.com/hacksurvivor/pathmark) | Local-first memory shared by Codex, Claude Code, Cursor, Gemini CLI and other MCP agents. One local file, no account. |
| [Dragoman](https://github.com/hacksurvivor/dragoman) | Claude plugin that localizes web, React Native and Apple apps and checks every translation. |
| [Burnmeter](https://github.com/hacksurvivor/burnmeter) | Your Claude and Codex usage limits in the menu bar. |
| [claude-mods](https://github.com/hacksurvivor/claude-mods) | Seven mods for Claude Code, including Nightshift, which runs Codex inside Claude Code. |

Also: [Scratchpad](https://github.com/hacksurvivor/scratchpad) (a design studio inside Codex) and [ai-sec](https://github.com/hacksurvivor/ai-sec) (allow, review or block what coding agents do).
